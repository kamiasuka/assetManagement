# 企业资产管理系统

## 项目背景

由于企业规模不断扩大，公司资产数量逐渐增多，手工记录难以满足管理需求。传统的资产管理方式可能存在着数据不准确、信息分散、跟踪不及时等问题，导致资产利用率低下、浪费资源、遗失或损坏等情况的发生。

为了解决这些痛点问题，开发一个企业资产管理系统成为必要的举措。该系统可以帮助企业实现资产数据集中管理，提高资产利用效率，优化资产配置和维护，避免资产损失，降低管理成本和风险。

企业资产管理系统是一种以软件形式实现的资产管理工具，旨在根据企业固定资产管理制度实际，实现资产保值增值及有效管理。主要 围绕“资产台账、资产使用(资产代管 与经营)、资产收入、资产处置、系统管理、基础信息、 附件管理”等核心功能 设计，覆盖企业资产业务管理的基本需求。

 

 

## 技术架构    

​     前端：     使用Vue3.x，Element 组件库，ECharts库

​     后端：     使用Spring+SpringMVC+MyBatis框架

​     数据库：     使用MySQL

 

## 功能模块     

### 一、系统首页     

模块功能：     

【系统登录】     

输入系统分配的单位版用户名和密码，点击登录按钮即可进入系统主页面，系统用户有两种角色： 

资产管理员（负责资产信息的录入、上报以及资产使用、处置等申请提交）

资产审核员（负责对资产管理员提交的资产使用、处置申请等进行审核）

【系统首页】

包括顶栏，左侧栏，内容区。

顶栏左侧显示了系统名称，右侧显示了系统用户名称，和“安全退出”按钮。

左侧栏为资产管理员可以操作的菜单界面。

内容区的上半部分展示的为固定资产的十二大分类（土地、房屋、构筑物、通用设备、专用设备、车辆、文物和陈列品、家具用具装具、图书档案、特种动植物、无形资产、在建工程） 的资产原值总计（包括未上报和已上报的资产）、资产数量总计、未上报的资产原值总计；下半部分展示了固定资产的数量柱状图 和资产价值来源统计饼状图。

【个人信息】

点击右上角的系统用户名称，点击个人信息页签，会显示当前登录用户的个人信息，
用户可以编辑修改本人用户姓名、电子邮箱、联系电话，密码。

【登出功能】

点击右上角的“安全退出”按钮，退出登录，回到登录页。

### 二、基本信息     

模块功能： 

【部门管理】     

点击基础信息-部门管理页签后可查看当前登录用户所在单位的部门列表，单位领导和财政审核员只有查看权限，资产管理员具有新增、修改、删除部门的权限，点击部门添加页签或者点击列表后的修改按钮，可对部门信息进行新增或修改，其中所属单位、部门名称为必填字段。

【资产分类】     

点击基础信息-资产分类页签后，内容区左侧会出现一个菜单，分别是所有资产的类型，展开菜单项可以看到对应分类的具体资产名，点击资产名，会在内容区展示该资产的所有基础信息。

### 三、附件管理     

模块功能：  

附件管理模块主要用于管理固有资产的相关附件资料，如图片、文档等；在查询资产时查看附件可以让用户对固有资产有更加清晰和全面的认识，提高用户的体验并协助用户完成对于资产的管理操作。

业务功能：

​      【附件管理】      点击菜单中的附件管理 点击查询页签后，附件列表页面中会显示数据库中所有的附件信息，在附件列表下的查询的页面中可根据附件类型、批次号、附件名称、使用状态进行附件信息查询，一个批次的资产附件可以被多次使用，已经被使用的附件不能被删除。 注意：只有资产管理员可以新增、修改、删除附件信息，资产审核员只能查看附件信息及文件。

​     【附件浏览】      点击右侧操作栏中的发附件浏览按钮，即可查看该附件批次所包含的文件内容。

​     【添加文件】      点击右侧操作栏中的添加文件按钮，可以在对应的附件中添加新的附件文件，方便对同一个批次的附件进行再次补充。

​     【选择文件】      添加附件时，可以直接从本地电脑中选择图片（JPG 或 PNG）进行添加，文件大小请控制在3M以内，可同时选择多张图片。

​     【上传文件】      选择好文件后，点击“上传文件”按钮，界面提示上传成功后，才将附件上传到服务器中，再次点击“确定”，附件才上传成功。

 

### 四、资产台账     

模块功能：     

​     【资产录入】     

录入资产信息：包括资产编码，资产名称，资产分类，所属单位，上报状态，审核状态，完成日期，价值类型，价值（元），使用状况，使用状况和操作选项。且可通过资产编码或者资产名称查询目标资产，并可手动刷新。其中资产录入由系统管理员操作，审核完成需由审核员操作完成，且可通过点击状态按钮进行操作。

在操作选项中，存在资产信息填充选项，点击可填写资产信息并保存。

存在附件选项可供资产提供有大小限制的文件类型附件。

​     【资产查询】     

点击资产台账-资产查询页签，管理员可看到本单位所有已录入的资产，而财务，领导等只能看到已上报的资产信息。对于未上报的资产，管理员可进行修改，对于已上报的资产，只能修改部分资产属性字段并生成日志文件保存。

点击资产详情按钮，可查看资产详情信息用于浏览。并存在资产历史按钮，查看资产处置历史记录。

可点击资产复制按钮对资产进行复制，只有管理员拥有此功能。

​     【资产上报】     

点击资产台账-资产上报页签，只有管理员拥有此功能，能对未上报资产进行修改删除上报，且可以批量操作，已上报资产会列入上报列表，并相应更改资产的上报状态。

 

### 五、资产处置     

模块功能：     

​     【资产报废】      

点击资产处置-资产报废页签，只有资产管理员拥有资产报废上报权限，对于未上报的资产报废申请，可以进行修改或删除操作，已上报的申请不能进行修改或删除。可根据资产报废申请的各个状态查询资产报废申请列表。

点击资产报废申请页签，填写资产报废申请单，选择资产报废附件，填写计划收益，勾选此次需要资产报废的资产信息，点击“提交”按钮，即可生成资产报废申请单。

资产报废申请填写完成后，需要点击资产报废页的“上报”按钮提交申请单后，需要资产审核员进行审核操作。

​     【资产报损】      

点击资产处置-资产报损页签，只有资产管理员拥有资产报损上报权限，对于未上报的资产报损申请，可以进行修改或删除操作，已上报的申请不能进行修改或删除，可根据资产报损申请的各个状态查询资产报损申请列表。

点击资产报损申请页签，填写资产报损申请单，选择资产报损附件，填写报损金额，勾选此次需要资产报损的资产信息，点击“提交”即可生成资产报损申请单。

资产报损申请填写完成后，需要点击“上报”按钮提交申请单后，需要资产审核员进行审核操作。

​     【资产调拨】     

点击资产处置-资产调拨页签，只有资产管理员拥有资产调拨上报权限，对于未上报的资产调拨申请，可以进行修改或删除操作，已上报的申请不能进行修改或删除，可根据资产调拨申请的各个状态查询资产调拨申请列表。

点击资产调拨申请页签，填写资产调拨申请单，选择资产调拨附件及目标单位，填写计划收益， 勾选此次需要资产调拨的资产信息，点击“提交”按钮，即可生成资产调拨申请单。

资产调拨申请填写完成后，需要点击“上报”按钮提交申请单后，需要资产审核员进行审核操作。

​     【出租出赁】     

点击资产使用-出租出借页签，只有资产管理员拥有出租出借上报权限，对于未上报的出租出借申请，可以进行修改或删除操作，已上报的申请不能进行修改或删除，可根据出租出借申请的各个状态查询出租出借申请列表。

点击出租出借申请页签，填写出租出借申请单，选择出租出借附件及目标单位，填写计 划收益，勾选此次需要出租出借的资产信息，点击“提交”按钮，即可生成出租出借申请单。

出租出借申请填写完成后，需要点击“上报”按钮提交申请单后，需要资产审核员进行审核操作。

 

###   六、收入管理     

​     模块功能          ：     

​     【收益管理】     

1.1.1点击收入管理-收益管理页面，只有资产管理员拥有添加修改删除权限，根据操作类型、单据号、入账状态、审核等各个状态查询收益信息列表。

1.1.2 点击收益添加，会显示所有需要添加收益的申请单，双击列表可录入该次操作所产生的收益情况，填写表单后点击提交按钮可以生成收益信息单。

​     【合同管理】     

1.2.1 点击收入管理-合同管理页面，只有资产管理员拥有资产合同的添加修改删除权限，可根据操作类型、合同号、合同类别、甲方名称、乙方名称、缴款方式各个状态查询合同信息列表。

1.2.2 点击合同添加页签，会显示所有需要添加合同的申请单，双击列表可录入该次操作所需要的合同情况，填写资产合同信息及合同附件，点击提交按钮，生成合同信息单。
